# RoomAI
A fullstack web application created using MERN stack, it is a image genration wrapper that helps user reimagine their rooms in different styles(like modern,classic,oldfashion...), to get inspiration for a new renovation work or build.

## Features
- Complete user authentication using jwt
- Email verification by sending a verification link to the user's email 
- For password reset, a reset link is send to the user's email
- Many styles to choose from which are fined tuned through prompt engineering 
## Tech stack
- React.js - fully custom UI / mobile first design
- Node.js - for backend
- Mongodb -  for database
- Gemini nano banana - AI service provider
- SendGrid mail - mailing service provider
## Future Scope
- migrating the database to postgresSQL
- using AI agents for better output
